

# ColorTooltips
ColorTooltips是一个提供提示框样式的模组。它的特点有两个，绚丽与灵动。
# 绚丽
独特的提示框设计，这真的很炫彩！  
![甚至有渐变效果](https://cdn.modrinth.com/data/cached_images/0d0dfa4abb9a7b33ad7bd5e264f258f2e6573745.gif)  
基于RarityCore的稀有度系统，每个稀有度都有自己的主题色。  
![rarity](https://cdn.modrinth.com/data/cached_images/b872f48b52f32c7a6b70dfef3dbb2ada5f09b009.gif)
# 灵动
这才是重头戏，相比其它提示框样式模组，ColorTooltips的动画遥遥领先！
## 色彩流动
现在边框和头部栏背景会有舒适的颜色流动。  
![色彩流动](https://cdn.modrinth.com/data/cached_images/0d0dfa4abb9a7b33ad7bd5e264f258f2e6573745.gif)
## 淡出淡入
不再有生硬的瞬间出现和消失！
- 现在提示框拥有淡出淡入的效果。
- 同时还有物品模型缓动，边框闪光效果！
- 颜色也有过渡动画！  
  ![淡出淡入](https://cdn.modrinth.com/data/cached_images/c15504c7fa6fa680440571d75d15bcbdd4e15863.gif)
## 过渡动画
当提示框大小改变，或是从鼠标右边切换到鼠标左边，都有一个非线性动画，非常护眼！
![大小缓动](https://cdn.modrinth.com/data/cached_images/d06cac52c38ccfde8a837596fcf526e81489f8b7.gif)  
![位置缓动](https://cdn.modrinth.com/data/cached_images/cf42ea5dde09d93d048a4e953ff624913d1e60da.gif)
# 兼容性
与 SearchCarefully 兼容！  
不兼容修改提示框样式的模组，但是兼容向其添加内容的模组。
# 配置项
你可以配置背景透明度和颜色流动效果，配置文件在config/colortooltips里。
